📦 PM工作台 · 数据迁移工具

把旧站（CloudStudio 旧域名）的全部数据迁移到本域名（EdgeOne 新站）。支持 localStorage + IndexedDB（含图片）全量搬迁。

① 在旧站导出 旧域名操作

  1. 打开旧站：7daa4a87bbcd4a23854a29487d540255.gz3.agentos-app.net
  2. 按 F12 打开开发者工具 → 切到 Console（控制台） 标签
  3. 把下方代码整段复制粘贴进去，按回车
  4. 会自动下载一个 pm-workbench-export-日期.json 文件，保存好
(async () => {
  const dumpIDB = (name) => new Promise((res) => {
    const req = indexedDB.open(name);
    req.onsuccess = (e) => {
      const db = e.target.result, stores = {}, names = Array.from(db.objectStoreNames);
      let n = names.length;
      if (!n) return res({ dbName: name, stores: {} });
      names.forEach((s) => {
        const tx = db.transaction(s, "readonly"), r = tx.objectStore(s).getAll();
        r.onsuccess = () => { stores[s] = r.result; if (--n === 0) res({ dbName: name, stores }); };
      });
    };
    req.onerror = () => res({ dbName: name, stores: {} });
  });
  const ls = {};
  for (let i = 0; i < localStorage.length; i++) { const k = localStorage.key(i); ls[k] = localStorage.getItem(k); }
  const idb = await dumpIDB("pm_workbench_images_v2");
  const payload = { __migration: "pm-workbench", v: 1, at: new Date().toISOString(), localStorage: ls, indexedDB: idb };
  const blob = new Blob([JSON.stringify(payload)], { type: "application/json" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = "pm-workbench-export-" + new Date().toISOString().slice(0, 10) + ".json";
  a.click();
  console.log("✅ 导出完成：", Object.keys(ls).length, "个 localStorage 键，", (idb.stores?.images?.length) || 0, "张图片");
})();

② 在本域名导入 新站操作

  1. 确保你正打开的是新站（本页面地址含 edgeone.cool）
  2. 点击下方区域，选择刚才下载的 .json 备份文件
  3. 等待导入完成（localStorage + 图片库全部写回）
  4. 导入后点底部「返回工作台」并刷新一次即可看到旧数据
⚠️ 重要提示：
1. 如果你在新站登录了云端同步账号，导入的本地数据可能在下次自动同步时被云端旧副本覆盖。建议导入后确认数据完整，或迁移期间先退出云端账号。
2. 导出代码只读取你浏览器里旧站的数据，不会上传任何内容；导入也仅写回你当前浏览器的新站域名。
3. 操作前可先在旧站「设置 → 下载完整备份」额外留一份 JSON 兜底。
